# 📝 Todo App

A minimal and clean **Todo List** built with **HTML**, **CSS**, and **JavaScript**.  
Add tasks, remove them, and keep everything saved in your browser using localStorage.

## 🚀 Features

- Add new todos
- Delete existing todos
- Automatically saved in `localStorage`
- Responsive and minimalist design
- Long text wraps neatly

## 🧠 Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## 📂 Project Structure

```bash
todo-app/
│
├─ index.html
├─ style.css
├─ main.js
│
├─ README.md
└─ .gitignore
```

## 💾 How to Run

1. Clone this repository
   ```bash
   git clone git@github.com:sabyryshka/todo-app-basic.git
   ```
2. Open the folder
   ```bash
   cd todo-app
   ```
3. Open **index.html** in your browser

That’s it — no build tools or dependencies needed.
